# 数据结构 · 平时作业代码

《数据结构》课程各章作业代码与实验报告。每章一个目录，含源码、输入样例和运行说明。

## 目录结构

```
.
├── ch02-线性表/         顺序表、单链表、双向链表
├── ch03-栈和队列/       顺序栈、链栈、循环队列
├── ch06-树和二叉树/     二叉树遍历、线索二叉树、哈夫曼树
├── ch07-图/             邻接矩阵、邻接表、DFS/BFS、最小生成树、最短路径
├── ch09-查找/           顺序查找、折半查找、二叉排序树、哈希表
├── ch10-排序/           插入、冒泡、快速、归并、堆排序
├── docs/                实验报告、运行截图
└── README.md
```

## 环境与运行

- 语言：C / C++（gcc 9+ 或 MinGW-w64）
- 编辑器：VS Code + C/C++ 插件
- 单文件编译运行：

```bash
gcc ch02-线性表/seqlist.c -o seqlist
./seqlist
```

- 若为 Python 实现：

```bash
python ch07-图/graph_dfs.py
```
